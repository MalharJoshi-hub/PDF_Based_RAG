2. ARCHITECTURAL LAYERS (7 Comprehensive Layers Verified)
--------------------------------------------------------------------------------
Layer 1: PDF Ingestion API & Gateway
         - Stream & byte validator (%PDF- magic bytes, size cap, MIME detection)
         - PyPDF2 text extraction with layout and control character sanitization
         - SHA-256 document hashing for deduplication
         - DocumentLoader and ExtractedPage domain models

Layer 2: Semantic Text Chunking Engine
         - StructuralChunker: regex header and chapter boundary detection
         - SlidingWindowChunker: configurable token/word overlap (150 words / 30 overlap)
         - RecursiveCharacterChunker: hierarchical splitting on paragraphs/sentences
         - TokenCounter: fast offline token estimation and word budgeting

Layer 3: Dense Representation & Embeddings
         - BaseEmbeddingProvider abstract interface
         - SentenceTransformerProvider: all-MiniLM-L6-v2 (384-dimensional float32)
         - EmbeddingCache: thread-safe LRU vector cache with MD5 key hashing
         - Embedder: batch vector coordinator and latency profiling

Layer 4: FAISS Vector Indexing Store
         - FAISSVectorStore: IndexFlatIP (Cosine Similarity on unit vectors)
         - Continuous 0..N-1 to Chunk ID mapping table (id_map.pkl)
         - IndexManager: lifecycle management, rebuilding, serialization, disk persistence

Layer 5: Relational Persistence Layer
         - SQLite database manager with WAL (Write-Ahead Logging) mode
         - Foreign key constraint enforcement (ON DELETE CASCADE)
         - DocumentRepository & ChunkRepository with batch insertion optimization
         - MigrationManager: automated schema evolution and legacy column migration

Layer 6: Multi-Retriever Orchestration & Neural Reranker
         - Dense Retriever: FAISS similarity search (<2 ms)
         - Sparse BM25: Okapi BM25 implementation for lexical matching
         - Baseline TF-IDF: Unigram/bigram cosine vector space model
         - Hybrid Retriever: Reciprocal Rank Fusion (RRF, k=60)
         - Neural Reranker: Cross-Encoder (cross-encoder/ms-marco-MiniLM-L-6-v2)

Layer 7: Generative QA Synthesis & Grounding
         - Google Flan-T5-base seq2seq generator with beam decoding (num_beams=3)
         - Repetition penalty (1.2) and anti-hallucination n-gram blocking
         - PromptBuilder: contextual key takeaway and definition extraction
         - CitationManager: page-level citations, relevance percentage, and snippet preview
